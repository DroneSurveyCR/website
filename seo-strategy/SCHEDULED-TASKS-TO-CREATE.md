# Scheduled Tasks — Create These in a Fresh Cowork Session

These two tasks need to be created from a **new** Cowork conversation (not this one).
Open a new Cowork session, paste the message below, and Claude will create both tasks.

---

## How to create them

1. Open a **new** Cowork conversation
2. Paste this message:

```
Please create two scheduled tasks for my DroneSurveyCR website blog automation:

TASK 1 — Tuesday blog post
- taskId: tuesday-blog-post-dronesurveycr
- Schedule: Every Tuesday at 8:00 AM (cron: 0 8 * * 2)
- Description: Write and publish Tuesday service/use-case blog post for DroneSurveyCR

TASK 2 — Friday blog post
- taskId: friday-blog-post-dronesurveycr
- Schedule: Every Friday at 8:00 AM (cron: 0 8 * * 5)
- Description: Write and publish Friday geo-targeted blog post for DroneSurveyCR

Read the full task prompts from:
/sessions/friendly-jolly-wright/mnt/Drone Survey CR Copy 2026/seo-strategy/TASK-PROMPT-TUESDAY.md
/sessions/friendly-jolly-wright/mnt/Drone Survey CR Copy 2026/seo-strategy/TASK-PROMPT-FRIDAY.md
```
